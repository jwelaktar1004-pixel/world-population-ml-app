🌍 Global Population Forecasting using Machine Learning
📌 Project Overview

This project analyzes historical global population data (1970–2022) and predicts future population growth for 2030 using Machine Learning.

The goal was to design a time-aware predictive modeling pipeline, engineer meaningful demographic features, and deploy the model as a production-ready interactive web application.

🎯 Objectives

Analyze long-term global population trends

Engineer time-based and lag-based features

Build a robust regression model

Prevent data leakage using time-aware split

Deploy a live ML-powered web dashboard

🛠 Tools & Technologies

Python

Pandas & NumPy

XGBoost Regressor

Plotly (Interactive Visualizations)

Streamlit (Web Deployment)

Git & GitHub (Version Control)

📊 Data Processing Pipeline

Wide → Long transformation

Year extraction and indexing

Log transformation to handle exponential growth

Lag feature engineering

Continent encoding

Time-aware train-test split

🤖 Machine Learning Model

Model Used: XGBoost Regressor

Why XGBoost?

Handles non-linear growth patterns

Strong performance on structured data

Robust to skewed distributions

Evaluation Metrics:

MAE (Mean Absolute Error)

R² Score
